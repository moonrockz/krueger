# Parser q56.3 Expanded Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Implement parser baseline (`krueger-q56.3`) for module/import/type/function declarations with parser diagnostics, partial recovery, and doc-comment attachment behavior.

**Architecture:** Add a new `src/parser/` package with parser contracts and implementation, then re-export parser APIs from root package. Keep AST/CST parser-owned and minimal in this phase so q56.4/q56.5 can evolve shape later. Drive all behavior with TDD (whitebox + blackbox + BDD).

**Tech Stack:** MoonBit, existing scanner contracts (`moonrockz/krueger/scanner`), MoonSpec BDD (`moonrockz/moonspec`), file-based `mise` tasks, lefthook pre-commit/pre-push checks.
